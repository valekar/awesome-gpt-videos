# Caveat font

Caveat variable TrueType font from the Google Fonts repository, retrieved 2026-10-18:
https://github.com/google/fonts/tree/main/ofl/caveat

Licensed under the SIL Open Font License, included as `OFL.txt`. This is an approximation of the reference lettering, not a claim that Caveat is the original font. Supplied as a separate shared rendering asset in adaptation iteration 2; the font was not generated by GPT-6.1.

Bangers-Regular.ttf is from https://github.com/google/fonts/tree/main/ofl/bangers (retrieved 2026-10-18), licensed under its separately included Bangers-OFL.txt. It is a comic-lettering approximation for the Negroni reference, not evidence that the original used that font.
